# Roadmap

## CORTANA–CMB–011 — Kernel Collapse
Add a second CMB channel, preferably polarization, and test whether combined channels:
- shrink the reconstruction kernel,
- raise weak singular values,
- improve conditioning.

## QCORE-001
Apply the same kernel/SVD architecture to a noisy quantum channel and syndrome measurements.

## LATENT-001
Recover hidden structure from probe deformation and optimize probe design to shrink the latent kernel.

## SPECTRA-001
Infer boundary/structural changes from eigenmode deformation; optimize sensor/excitation placement.

## Cross-domain criterion
The architecture earns stronger generality only if the same core computation produces useful diagnostics across all three branches.
