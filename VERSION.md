# Version History

## v0.1.0 — Initial Public Research Scaffold

**Release date:** 2026-06-06

This release establishes the public research scaffold for **Coherence Under Constraint (CUC)**.

### Added

- Cleaned top-level README.
- Core thesis: `Structure = Coherence × Constraint × Throughput`.
- Boundary language clarifying that CUC is not a new fundamental force, not a replacement for domain sciences, and not a closed theory.
- Initial formal backbone using coherence threshold, throughput balance, and constrained dynamics conditions.
- Research questions and initial predictions.
- Citation metadata.
- Documentation scaffold.
- Simulation scaffold.

### Current Status

CUC is conceptually drafted and ready for computational validation.

It is not yet empirically validated or peer reviewed.
