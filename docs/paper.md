# Coherence Under Constraint: working-paper status

**Author:** Gage Fry  
**Current canon:** v0.2.0-draft.1  
**Status:** Manuscript reconstruction pending benchmark results

The original v0.1 working-paper scaffold has been superseded as the formal source by the [`CUC Canon v0.2 Charter`](../CHARTER.md).

The next paper should not simply restate the Charter. It should be rebuilt around:

1. a concise problem statement and relation to established work;
2. the organizational-survival definition;
3. preregistered hypotheses;
4. the modular reference benchmark;
5. comparisons with ordinary dynamical and statistical baselines;
6. reproducible results, including null and negative findings;
7. limits on cross-domain interpretation.

Until those results exist, the Charter is the authoritative specification and this file is a manuscript roadmap rather than a scientific paper.

## Proposed paper title

**Coherence Under Constraint: Organizational Survival, Interface Failure, and Return in a Modular Dynamical Benchmark**

## Proposed abstract structure

- Problem: persistence is often conflated with coherence or static stability.
- Method: define organizational survival independently and manipulate coupling, constraint, throughput, topology, noise, and perturbation.
- Comparison: evaluate Fource and multiscale CUC variables against ordinary coupling and flexible predictive baselines.
- Results: report held-out survival, calibration, failure localization, and return behavior.
- Boundary: limit claims to the tested model class and identify requirements for domain translation.

## Evidence rule

No result should enter the abstract until it is linked to a reproducible experiment manifest. Illustrative curves and historical prototypes must remain labeled.

The v0.1 manuscript remains recoverable from repository history.
