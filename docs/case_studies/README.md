# Case Studies

This directory will hold applied case studies for Coherence Under Constraint (CUC).

Planned case study areas:

1. **Coupled oscillators** — coherence threshold behavior in simple dynamic systems.
2. **AI memory systems** — chronology, provenance, contradiction tracking, and retrieval coherence.
3. **Biological organization** — membranes, homeostasis, and adaptive boundaries.
4. **Social systems** — institutions, trust networks, norms, and resource flow.
5. **Technological systems** — protocols, databases, distributed systems, and interface stability.

Each case study should include:

- domain description;
- relevant substrate;
- coherence measure;
- constraint type;
- throughput type;
- transition or failure mode;
- testable prediction;
- limitations.
