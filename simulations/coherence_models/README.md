# Coherence Models

This directory will contain computational models for testing coherence behavior under changing constraints.

Initial planned model:

## Coupled Oscillator Coherence Test

Purpose:

- simulate a network of coupled oscillators;
- measure coherence using an order parameter such as `R(t)`;
- vary coupling strength and constraint conditions;
- identify threshold behavior and coherence basin formation.

Expected outputs:

- time series of oscillator phases;
- coherence score over time;
- threshold transition plots;
- notes comparing model behavior to CUC predictions.

Planned implementation:

- Python;
- NumPy;
- Matplotlib;
- simple reproducible script before adding complex models.
